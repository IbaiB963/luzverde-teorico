# Luz Verde · Teórico B

Aplicación web gratuita para preparar el examen teórico del permiso B: camino por temas, práctica libre, simulacros de 30 preguntas, vídeo-lecciones narradas y repaso inteligente.

Todas las preguntas, explicaciones y lecciones son de elaboración propia a partir de la normativa vigente. No es un servicio de la DGT ni contiene preguntas oficiales del examen.

El progreso se guarda solo en el navegador de cada usuario.
